# /画本

## 任务

把给定原文转换为可供配音、审听、对轨和后期使用的结构化稿件。

## 输入

- 原始文本或指定章节文件。
- 已知角色表（可选）。
- 已知场景、世界观和发音词典（可选）。

## 执行规则

1. 按自然语义拆分句子或配音单元，每个单元生成唯一且稳定的 `segment_id`。
2. 判断每个单元属于 `narration`、`dialogue`、`inner_voice`、`reading`、`sound_direction` 或 `music_direction`。
3. 对对话推断角色；只使用原文和已提供的上下文，不凭空创建角色。
4. 标注情绪、语速、重音、停顿、发音和场景属性。没有依据时使用 `unknown`，不要伪造精确值。
5. 对角色归属、语气或文本边界不确定的单元设置 `review_required: true`，并写明原因。
6. 保留原文内容。任何润色、删改或口语化建议必须单独放在 `suggestions`，不得覆盖 `text`。
7. 输出必须符合 `schemas/script-segment.schema.json`。

## 输出

输出 JSON 数组或带 `segments` 字段的 JSON 对象。每个单元至少包含：

- `segment_id`
- `type`
- `speaker`
- `text`
- `emotion`
- `pace`
- `review_required`

推荐同时输出一份人类可读的 Markdown 配音稿，但 JSON 是下游流程的唯一事实来源。

## 质量门槛

- 角色名必须来自角色表、前文明确介绍或明确的称谓推断。
- 旁白不能因为没有引号就自动成立；结合段落语义判断。
- 不确定的归属必须显式标记。
- `segment_id` 在后续审听和对轨中不得重新生成。
